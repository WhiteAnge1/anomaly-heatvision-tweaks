# Проверка HeatVision Green Channel Fix 1.2.0-rc4

RC4 меняет только FOMOD/MO2-метаданные. Shader-файлы, Lua-логика и MCM идентичны принятой RC3.

1. Оставить исходный `[Геймплей_S] HeatVision_v1.3` включённым.
2. Отключить RC3 патча и установить RC4 обычной кнопкой MO2 «Установить».
3. FOMOD должен сразу предложить имя `[Патч] HV_GCF by White_Angel v1.2`.
4. В колонке «Версия» должна отображаться `1.2.0-rc4`, а не дата.
5. Поставить RC4 ниже исходного HeatVision, удалить папку `appdata\shaders_cache` целиком и запустить игру.
6. Загрузить сохранение и убедиться, что вкладка HeatVision MCM открывается, значение зелёного канала сохраняется и прежнего Lua-вылета нет.

Новая игра не нужна. Полный повтор shader-регрессий не требуется, поскольку содержимое shader/runtime-файлов не менялось.
