# Проверка HeatVision Green Channel Fix 1.2.0-rc3

## Установка и метаданные MO2

1. Полностью закрыть игру.
2. Оставить исходный `[Геймплей_S] HeatVision_v1.3` включённым.
3. Отключить RC2 патча и установить RC3 обычной кнопкой MO2 «Установить».
4. Как у AER, FOMOD должен сразу выбрать имя `[Патч] HeatVision Green Channel Fix by White_Angel v1.2.0-rc3`; вручную выбирать короткий вариант `HeatVision` не нужно.
5. В колонке «Версия» должна отображаться `1.2.0-rc3`, а не дата.
6. Расположить патч ниже исходного HeatVision.
7. После уже выполненного полного удаления `shaders_cache` дополнительная очистка не требуется.

## Загрузка и MCM

1. Загрузить сохранение в убежище: вылета `z_heatvision.script:448 hud nil` быть не должно.
2. Открыть существующую вкладку HeatVision.
3. Проверить русскую подпись и tooltip параметра «Вклад зелёного теплового канала».
4. Убедиться, что отображается default `0.25`, диапазон `0.00–1.00`, шаг `0.05`.
5. Изменить значение, нажать «Применить», закрыть и снова открыть MCM: выбранное значение должно сохраниться.

Полный повтор shader-регрессий не требуется: shader-файлы RC3 идентичны RC2.
