# Проверка HeatVision Green Channel Fix 1.2.0-rc2

## Установка и метаданные MO2

1. Полностью закрыть игру.
2. Оставить исходный `[Геймплей_S] HeatVision_v1.3` включённым.
3. Установить RC2 отдельным модом через обычную кнопку MO2 «Установить».
4. Проверить предложенное имя: `[Патч] HeatVision Green Channel Fix by White_Angel v1.2.0-rc2`.
5. Проверить, что в колонке «Версия» отображается `1.2.0-rc2`, а не дата.
6. Расположить патч ниже исходного HeatVision.
7. После уже выполненного полного удаления `shaders_cache` дополнительная очистка не требуется.

## MCM

1. Открыть существующую вкладку HeatVision.
2. Проверить русскую подпись и tooltip параметра «Вклад зелёного теплового канала».
3. Убедиться, что отображается default `0.25`, диапазон `0.00–1.00`, шаг `0.05`.
4. Изменить значение, нажать «Применить», закрыть и снова открыть MCM: выбранное значение должно сохраниться.

Повторный полный тест уже принятой shader-логики RC1 для этого metadata-only RC2 не требуется.
