# HeatVision Green Channel Fix by White_Angel

Статус: **1.2.0-rc4 — публичный релиз-кандидат**.

Зависимый патч для HeatVision v1.3 в S.T.A.L.K.E.R. Anomaly / GRA. Он исправляет ложную тепловую маску на статической геометрии, сохраняет подсветку персонажей и добавляет в существующую вкладку HeatVision MCM настройку вклада зелёного теплового канала.

RC4 меняет только установочное имя: FOMOD предлагает короткое `[Патч] HV_GCF by White_Angel v1.2`, чтобы уменьшить глубину путей MO2 и риск ошибок Windows при работе с глубоко вложенными файлами. Публичное название проекта остаётся **HeatVision Green Channel Fix**, а игровая логика, шейдеры и MCM совпадают с RC3.

## Что меняется

- красный канал тепла применяется только к skinned-моделям персонажей и мутантов;
- окна, кроны и другая статическая геометрия больше не наследуют красную маску из-за порядка отрисовки;
- зелёный канал частиц и аномалий сохраняется, но его вклад регулируется в MCM;
- значение применяется во время игры через уже существующий shader-параметр HeatVision, без повторной очистки shader cache после каждого изменения.

## Совместимость и зависимости

- требуется установленный **HeatVision v1.3 [DLTX]**;
- требуется совместимый modded X-Ray/Monolith с поддержкой HeatVision;
- рассчитано на используемый в GRA рендер `r3` (DX10/DX11);
- патч заменяет `gbuffer_stage.h`, `infrared.h`, `infrared_utils.h`, `z_heatvision.script` и `z_heatvision_mcm.script`, поэтому конфликтует с другими модами, изменяющими те же файлы.

## Установка через MO2

1. Установить и включить исходный HeatVision v1.3.
2. Установить этот патч отдельным модом через встроенный FOMOD. MO2 должен сразу использовать короткое имя `[Патч] HV_GCF by White_Angel v1.2` и указать полную версию `1.2.0-rc4` в отдельной колонке.
3. Расположить патч **ниже HeatVision v1.3**, чтобы его файлы имели больший приоритет.
4. Перед первым запуском после установки удалить папку `appdata\shaders_cache` целиком.

После первой компиляции шейдера изменение ползунка не требует повторной очистки cache.

## Настройка

Откройте `Настройки → Конфигурация MCM → HeatVision`.

Параметр **«Вклад зелёного теплового канала»**:

- диапазон: `0.00–1.00`;
- шаг: `0.05`;
- значение по умолчанию: `0.25`;
- `0.00` — полностью убирает вклад зелёной маски частиц и аномалий;
- `0.25` — проверенный компромисс исправления;
- `1.00` — исходная полная яркость зелёного канала HeatVision v1.3.

Настройка не меняет красный канал людей, мутантов и трупов.

## Удаление

Отключить патч в MO2 и удалить папку `appdata\shaders_cache` целиком, чтобы движок пересобрал исходные шейдеры HeatVision.

## Проверка релиза

Игровая логика RC4 идентична принятой сборке RC3, для которой подтверждено:

- FOMOD устанавливает патч отдельным модом, а MO2 отображает полную версию;
- сохранение загружается без прежнего Lua-вылета из-за ещё не созданного HUD;
- настройка присутствует в существующей вкладке HeatVision MCM, изменяется, применяется и сохраняет выбранное значение.

Shader-логика и визуальные коэффициенты в RC4 не менялись относительно проверенной RC3.
